# Swing Advisor - Features

## Core Features

### 1. Strategy Analysis
Advanced AI-powered swing trading strategy evaluation with:
- 6 institutional-grade strategies
- Multi-bar confirmations
- Risk/reward validation
- Historical backtesting (12 months)
- AI mentor guidance

### 2. Deep Analysis
Comprehensive ticker analysis with:
- Chart pattern detection (two-tier system)
- Technical indicators (EMAs, RSI, MACD, ATR)
- Volume analysis
- Institutional-grade scoring

### 3. Strategy Builder
Create custom strategies from plain English:
- LLM-powered parser (OpenAI GPT-4o-mini)
- Type-safe DSL with Zod validation
- Expression-based levels (entry+1.5*ATR)
- Auto-prioritized over core strategies
- Full CRUD management

### 4. Market Scanner
*(Coming Soon)*
Scan the market for best swing trading setups

### 5. Account Management
- Profile editing
- Password changes
- Usage statistics
- Strategy tracking

## Technical Stack

- **Frontend**: Next.js 15, React, TypeScript, TailwindCSS
- **Backend**: Next.js API Routes, NextAuth
- **Database**: PostgreSQL with Prisma ORM
- **Data**: Polygon.io API
- **AI**: OpenAI GPT-4o-mini
